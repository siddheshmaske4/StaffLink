# StaffLink

## Enterprise Management System

StaffLink is an Android-based enterprise management system designed to help organizations manage employee-related operations through a centralized mobile application.

The application provides features for employee management, attendance, internal communication, task management, profile management, and other organizational workflows.

## Features

- Employee Management
- Admin Dashboard
- Employee Dashboard
- Attendance Management
- Geo-Network Based Attendance Restriction
- Internal Mail System
- Task Creation and Assignment
- Task Tracking
- Task Acknowledgement
- Profile Management
- Firebase Realtime Database Integration
- Centralized Enterprise Management

## Key Modules

### Dashboard
Provides centralized access to important application functions and management features.

### Attendance Management
Attendance functionality includes geo-network based restrictions to help ensure attendance actions are performed under authorized workplace conditions.

### Task Management
The task management system allows users to:

- Create tasks
- Assign tasks
- Track assigned tasks
- Acknowledge tasks

### Internal Mail System
Provides an internal communication system for sending and managing messages within the application.

### Profile Management
Provides users with a dedicated profile section for managing their profile-related information.
